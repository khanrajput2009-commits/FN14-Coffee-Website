# FN14 Coffee Shop Website ☕🥐

A modern, cozy, and fully responsive website for a coffee shop built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
Check out the live website here: 
[https://khanrajput2009-commits.github.io/FN14-Coffee-Website/](https://khanrajput2009-commits.github.io/FN14-Coffee-Website/)

---

## ✨ Features
* **Cozy & Modern UI/UX:** Warm and inviting design tailored for coffee lovers.
* **Interactive Coffee Menu:** Showcase of hot/cold brews, pastries, and special offers.
* **About & Contact Sections:** Clear brand story and quick access to location and hours.
* **Fully Responsive:** Smooth layout across mobile, tablet, and desktop screens.

---

## 🛠️ Technologies Used
* **HTML5** - Page structure and semantic elements
* **CSS3** - Custom styling, flexbox layout, and responsive media queries
* **JavaScript** - Interactive components and dynamic UI behavior
